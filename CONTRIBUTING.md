# Contributing to Laundry Management System

First off, thank you for considering contributing to the Laundry Management System! It's people like you that make open source such a great community.

## How Can I Contribute?

### Reporting Bugs

If you find a bug in the project, please open an issue on GitHub. When reporting an issue, please include:
- A clear and descriptive title.
- A detailed description of the problem.
- Steps to reproduce the issue.
- Your environment (OS, Java version, Maven version, Application Server).

### Suggesting Enhancements

If you have an idea for an enhancement, please open an issue and explain:
- Why the enhancement would be useful.
- How it should work.
- Any potential alternatives you've considered.

### Pull Requests

1. **Fork the repository** on GitHub.
2. **Clone your fork** locally.
3. **Create a new branch** for your feature or bug fix:
   ```bash
   git checkout -b my-new-feature
   ```
4. **Make your changes** and commit them with descriptive commit messages.
5. **Test your changes** to ensure they do not break existing functionality.
6. **Push your branch** to your fork:
   ```bash
   git push origin my-new-feature
   ```
7. **Open a Pull Request** against the `main` or `master` branch of the original repository.

## Coding Standards

- Follow standard Java coding conventions.
- Use meaningful variable and method names.
- Document complex logic and public APIs using JavaDoc.
- Ensure your code compiles without warnings and passes all existing tests.

Thank you for contributing!
